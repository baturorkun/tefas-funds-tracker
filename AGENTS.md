# Repository instructions

## `fon.dat` safety rule

Before modifying `fon.dat`, create a timestamped backup of its current contents
inside the repository's `backup/` directory.

- Use the filename format `backup/fon.dat.YYYYMMDD-HHMMSS.backup`.
- Create the `backup/` directory if it does not exist.
- Complete and verify the backup before editing `fon.dat`.
- If the backup cannot be created, do not modify `fon.dat`; report the failure.
- Never overwrite or delete an existing backup while performing a `fon.dat`
  edit.
